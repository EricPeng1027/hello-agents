    空闲

      确认大纲

      规划完成。可编辑标题与各章要点后确认，Agent 将按此大纲逐章撰写。

      下载：Markdown · DOCX

      修改意见

      章节专属意见请直接填在上方各章卡片下方的输入框里。

      使用说明

      1. 左侧选择材料类型（各类型材料独立存放：data/<类型>/facts|style），可先把参考材料上传到当前类型的库（支持 CSV/XLSX 数据表）
      2. 点击「开始撰写」直接生成；或点「💬 对话式撰写」用几轮对话明确需求后再生成；点「🗂 材料管理」查看/删除/同步各类型材料
      3. Agent 先规划章节大纲，完成后在右侧确认或编辑，随后逐章撰写并自评打分
      4. 成稿展示在右侧（含各章评分），可下载 MD/DOCX；填写修改意见可增量修订
