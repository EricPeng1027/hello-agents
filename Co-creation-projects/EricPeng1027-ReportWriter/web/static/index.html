    使用说明

    1. 选择材料类型（各类型材料独立存放：data/<类型>/facts|style），可先把参考材料上传到当前类型的库（支持 CSV/XLSX 数据表）
    2. 「开始撰写」直接生成大纲；「💬 对话式撰写」先用几轮对话明确需求再生成
    3. Agent 规划章节大纲后在此确认或编辑，随后逐章撰写并自评打分
    4. 成稿含各章评分，可下载 MD/DOCX；填写修改意见可增量修订
    5. 「🗂 材料管理」查看/删除/同步材料；「⚙️ 类型配置」自定义章节骨架与提示词

    确认大纲

    规划完成。可编辑标题与各章要点后确认，Agent 将按此大纲逐章撰写。

    下载：Markdown · DOCX

    修改意见

    章节专属意见请直接填在上方各章卡片下方的输入框里。
