      确认大纲

      规划完成。可编辑标题与各章要点后确认，Agent 将按此大纲逐章撰写。

      下载：Markdown · DOCX

      修改意见

      章节专属意见请直接填在上方各章卡片下方的输入框里。

      使用说明

      1. 左侧选择材料类型、填写主题（可先把参考材料上传到事实/风格库）
      2. 点击「开始撰写」：Agent 先规划章节大纲，完成后在右侧确认或编辑
      3. 确认大纲后 Agent 逐章撰写并自评，成稿展示在右侧，可下载 MD/DOCX
      4. 阅读后填写修改意见（全局或按章节），提交后 Agent 增量修订并重新导出
